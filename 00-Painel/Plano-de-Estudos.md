# Plano de Estudos: Migração Backend Java $\rightarrow$ Data Engineer

Este plano intercala Python e SQL para evitar fadiga cognitiva e construir o portfólio em camadas.

## 🗓 Ciclo de Estudo por Capítulo
| Dia | Atividade | Objetivo |
| :--- | :--- | :--- |
| **Dia 1** | Aula + Lab | Compreender a teoria e prever resultados. |
| **Dia 2** | Tickets | Resolver problemas reais (Simulação de Job). |
| **Dia 3** | Revisão D1 + Mista | Fixação imediata e recuperação ativa. |
| **Dia 5** | Chefe + Entrega | Integração e documentação de portfólio. |
| **Dia 8** | Revisão D7 | Consolidação de longo prazo. |

## 🗺 Roadmap de Execução

### Fase 1: Fundamentos (Semanas 1-4)
- **Foco:** Sintaxe Python moderna e SQL DQL/DDL.
- **Python:** Cap 01 $\rightarrow$ 04.
- **SQL:** Cap 01 $\rightarrow$ 03.
- **Marco:** Setup do ambiente Docker + Primeiro script de extração CSV.

### Fase 2: Manipulação e Modelagem (Semanas 5-8)
- **Foco:** Pandas, SQLAlchemy e Window Functions.
- **Python:** Cap 05 $\rightarrow$ 08.
- **SQL:** Cap 04 $\rightarrow$ 07.
- **Marco:** Modelagem do Star Schema da Loja Aurora.

### Fase 3: Performance e Escala (Semanas 9-12)
- **Foco:** Otimização SQL, Parquet e APIs.
- **Python:** Cap 09 $\rightarrow$ 12.
- **SQL:** Cap 08 $\rightarrow$ 12.
- **Marco:** Pipeline de 1 bilhão de linhas (simulado).

### Fase 4: Especialização DE (Semanas 13-16)
- **Foco:** Airflow, Qualidade de Dados e Data Lake.
- **Eng. Dados:** Todos os 6 capítulos.
- **Estrutura de Dados:** Todos os 6 capítulos.
- **Marco:** Projeto Integrador Final.
