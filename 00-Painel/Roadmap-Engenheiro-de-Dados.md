# Roadmap do Engenheiro de Dados Júnior

Este roadmap guia a transição de Backend Java para Data Engineering, focando em portfólio.

## 🛠 Stack Tecnológica Alvo
- **Linguagem:** Python 3.12 (Foco em Data Science stack).
- **Banco de Dados:** PostgreSQL 16+.
- **Armazenamento:** Parquet / AWS S3 (simulado local).
- **Orquestração:** Apache Airflow.
- **Infra:** Docker / Docker Compose.
- **Qualidade:** Pytest / Great Expectations.

## 🚀 Marcos de Portfólio (Milestones)

### Milestone 1: O Extrator (Semanas 1-4)
- **Entrega:** Script Python que lê APIs/CSVs, valida tipos e salva em SQL.
- **Habilidade:** Manipulação de arquivos, tratamento de erros, SQL básico.

### Milestone 2: O Analista (Semanas 5-8)
- **Entrega:** Dashboard de métricas complexas usando Window Functions e CTEs no PostgreSQL.
- **Habilidade:** SQL Avançado, Modelagem Relacional.

### Milestone 3: O Arquiteto (Semanas 9-12)
- **Entrega:** Pipeline idempotente que processa milhões de linhas usando Pandas e Parquet.
- **Habilidade:** Performance, Memória, SQLAlchemy 2.0.

### Milestone 4: O Engenheiro (Semanas 13-16)
- **Entrega:** Pipeline orquestrado no Airflow com camadas Bronze/Silver/Gold e testes de qualidade.
- **Habilidade:** Orchestration, Data Quality, Docker.

## 🎯 Diferenciais para Vagas Júnior
- **Saber explicar o "Porquê":** Não apenas o código, mas a decisão (Ex: "Usei Parquet porque a leitura colunar é mais eficiente para agregações").
- **Testes Automatizados:** Projetos com `pytest` demonstram maturidade de software engineer.
- **Documentação:** READMEs impecáveis com diagramas Mermaid.
