# 📖 Manual de Instruções do Vault

Bem-vindo ao seu ecossistema de aprendizado de Engenharia de Dados. Este Vault não é apenas um repositório de notas, mas um **simulador de trabalho**. Ele foi desenhado para transformar a teoria em competência técnica para portfólio.

---

## 🗺️ 1. Como Navegar no Sistema

### O Centro de Comando (`00-Painel`)
- **`Dashboard.md`**: Sua tela inicial. Utiliza o plugin **Dataview** para mostrar automaticamente o que você precisa revisar hoje e seu progresso real nas trilhas.
- **`Plano-de-Estudos.md`**: O cronograma sugerido. Intercala Python e SQL para evitar a fadiga cognitiva.
- **`Caderno-de-Erros.md`**: Seu ativo mais valioso. Anote aqui cada erro difícil que resolveu. Consultar este arquivo antes de entrevistas técnicas é o seu "cheat code".

### Os Mapas de Conteúdo (`MOCs`)
Em vez de navegar pelas pastas, use o `MOC-Python.md` e o `MOC-SQL.md`. Eles contêm:
- **Mapa de Progressão:** Um gráfico visual de dependências.
- **Links Rápidos:** Acesso direto a todas as aulas, labs e entregas.

---

## 🎓 2. A Metodologia de Estudo (O Ciclo)

Para cada capítulo, siga rigorosamente a sequência de 7 arquivos:

| Ordem | Arquivo | O que fazer? | Objetivo |
| :--- | :--- | :--- | :--- |
| 1 | **`01-Aula`** | Ler a teoria e as "Armadilhas". | Base teórica e contexto de pipeline. |
| 2 | **`02-Lab`** | Resolver os exercícios "Complete" e "Do Zero". | Aplicação imediata. |
| 3 | **`03-Tickets`** | Resolver os problemas simulando um Job de Jira. | Pensamento crítico e resolução de problemas. |
| 4 | **`04-Gabarito`** | Comparar a lógica e ler o "Raciocínio". | Validação técnica. |
| 5 | **`05-Flashcards`** | Praticar o *Active Recall* (cobrir e responder). | Memorização de longo prazo. |
| 6 | **`06-Revisao`** | Executar o checklist de competências. | Garantir que não há lacunas. |
| 7 | **`07-Entrega`** | Construir o projeto para o GitHub. | Prova real para o portfólio. |

---

## ⚙️ 3. Configurações Técnicas (Plugins)

Para que este Vault funcione, você deve ter os seguintes plugins instalados e ativos:

1. **Dataview**: 
   - **Função:** Alimenta o Dashboard automaticamente.
   - **Configuração:** Ative `Enable JavaScript Queries` e `Enable Inline Queries` nas configurações do plugin.
2. **Templater**: 
   - **Função:** Padroniza a criação de novas notas usando a pasta `Templates`.

---

## 🚀 4. Dicas de Ouro para o Aluno

- **Não pule os Tickets:** A diferença entre um programador e um Engenheiro de Dados é a capacidade de resolver problemas de performance e estabilidade. Os tickets treinam isso.
- **Imutabilidade e Memória:** Em Python, foque obsessivamente em entender o consumo de RAM e a imutabilidade. É isso que separa os juniores dos plenos.
- **Documente seu Portfólio:** Tudo o que for feito nos arquivos `07-Entrega-Projeto` deve ser versionado no GitHub com um README impecável.
